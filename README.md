## 简介

一个轻量的在线图片压缩工具，主打「上传前先瘦身」：把大图压到能直接用于公众号、详情页和投稿的体积，画质肉眼基本无感。所有处理都在本地浏览器完成，图片不会离开你的电脑。

## 功能

- **多格式支持**：JPEG、PNG、WebP 输入，可输出为更适合网络的格式
- **体积对比**：压缩前后大小一目了然
- **批量处理**：多张图片一起压，结果可批量导出
- **纯本地**：不传服务器，断网也能用
- **零依赖**：打开网页即用

## 技术栈

HTML5 Canvas · JavaScript · 浏览器端编码（无后端）

## 使用

打开页面 → 选择或拖入图片 → 调整压缩质量 → 下载结果。
